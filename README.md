# Mister Toy 🧸

## Mister Toy Description

Mister Toy is your ultimate online destination for all things fun and playful! Whether you're searching for the perfect toy, 
keeping an eye on the latest trends, or just exploring for fun, we've got you covered. With a vibrant interface, powerful features, and a sprinkle of joy, Mister Toy is here to make your toy-shopping experience delightful.

**This is the backend repository of Mister Toy, frontend is right [here](https://github.com/RonFelsenfeld/MisterToy-TS-Frontend).**

## Technologies

- GraphQL
- Mongo DB

## Packages

- apollo/server - For managing the graphQL server.
- bcrypt & crypto-js - For authentication tokens management and handling.
- cors - For enabling CORS.
- cookie-parser - For allowing cookies.

## Local Installation

**1. Clone the repo:**

```
git clone https://github.com/RonFelsenfeld/MisterToy-TS-Backend.git
```

**2. Navigate to the project directory and install dependencies:**

```
cd Mister-Toy-Backend
npm install
```

**3. To run server:**

```
npm start
```

**4. Install [MisterToy-TS-Frontend](https://github.com/RonFelsenfeld/MisterToy-TS-Frontend) locally and run the client.** <br>
_(Follow the instructions in it's README file)_
